# UCI447: Condition monitoring of hydraulic systems

Оригинал: https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems
DOI10.24432/C5CW21. Авторы: Nikolai Helwig, Eliseo Pignanelli, Andreas Schütze.
Лицензия официальной карточки: CC BY4.0; при использовании нужна атрибуция.

Локально сохранён полный ZIP76 601 704байт (исключён изGit). Оглавление/SHA256
и CRC/хеши четырёх проверенных членов — `manifest.json`. Распакованы только
`description.txt`, `documentation.txt`, `profile.txt`; код читает PS1 из архива
в памяти. Метаданные сохранены исходными байтами, возможна legacy-кодировка.
Все остальные измерительные каналы численно не проверены.

Повторить загрузку/аудит: `python -m scripts.audit_uci447` из корня проекта.
Сверка существующего снимка: та же команда с `--check`. Без локального ZIP
загрузчик получает полный архив с ограничением100МиБ. Отличающиеся сохранённые
файлы/таблицы не перезаписываются. `--archive` позволяет использовать уже
полученный оригинальный ZIP. Новых зависимостей нет, модели не загружаются.

Отчёт: `docs/results/uci447_audit.md`, таблицы: `results/uci447_audit_v1/`.
Это ограниченный структурный аудит, не утверждённые эталоны/протокол H1–H3.
60-секундные циклы не склеивать; stable-флаг не является границей внутрициклового
устойчивого участка. Непрерывность и независимость между циклами не установлены.
