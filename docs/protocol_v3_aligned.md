## 1. Идея простыми словами

Вместо того чтобы выбрасывать старую часть контекста, её «подгоняют» под недавний режим: сдвигают уровень, масштабируют разброс или меняют наклон тренда. Форма колебаний (сезонность, автокорреляция) остаётся. Модель получает контекст той же длины 512, но со старой частью, приведённой к текущему режиму. Какое преобразование применить, решает проверка «назад» на 16 уже известных точках.

## 2. Данные и конфигурации

- synth_v1 **seed 0** (отчёт). Настраиваемых параметров в основном методе нет, поэтому seed 1 не используется.
- Основная конфигурация: Chronos-Bolt-small, H = 64, CPU. Дополнительно: Bolt H = 16 (начало H64), Chronos-2 H = 64 и H = 16 (GPU, отдельный вызов на каждый H).
- Окна: pos ≥ −112 (нужен прогноз окна pos − 16), исключения как в пилоте Multi-Context.

## 3. Разбиение контекста

Контекст C = x[t − 511 … t] (L512). Недавний участок R — последние **W = 64** точки, старый O — первые 448. Разбиение фиксировано и не использует τ, тип смены или детектор. R никогда не меняется. s(t) — наивный масштаб C.

## 4. Преобразования старого участка

Статистики считаются только по O и R этого же контекста (то есть только по истории до t).

| Код | Формула для O′ | Защиты |
| --- | --- | --- |
| level | O − med(O) + med(R) | — |
| scale | med(R) + k · (O − med(O)), k = MAD(R) / MAD(O), k ограничен [0.1, 10] | если MAD(O) или MAD(R) < 1e-3 · s(t) — применяется level; число таких окон записывается |
| trend | (O − ℓ_O) + ℓ_R, где ℓ_O — МНК-прямая по O, ℓ_R — МНК-прямая по R, продолженная назад на индексы O | — |

MAD — медиана абсолютных отклонений от медианы (без множителя 1.4826). МНК-наклон на 64 точках смещается сезонностью с периодом до 48 — известное ограничение, не подбирается.

**Частичная коррекция:** O_α = (1 − α) · O + α · O′, α ∈ {0.25, 0.5, 0.75}; α = 1 — полная коррекция, α = 0 — Original.

## 5. Кандидаты, hindcast и выбор

Кандидаты: **Original** (кеш L512), **Short** (кеш L64 = R), **level**, **scale**, **trend**.

Ошибка «назад» кандидата в момент t — MAE медианы его прогноза, построенного в окне pos − 16 (то есть по истории до t − 16, тем же правилом разбиения и преобразования), на x[t − 15 … t]. Прогноз выровненного кандидата окна pos − 16 и есть этот hindcast: скрытые 16 точек не входят ни в контекст, ни в статистики O/R. Для Original и Short — кеш, как в пилоте.

Выбор — argmin ошибки «назад»; при разнице < 1e-6 · s(t) приоритет в порядке наименьшего вмешательства: Original, level, scale, trend, Short.

## 6. Методы

| Код | Что | Роль |
| --- | --- | --- |
| **sel_align** | выбор из Original, Short, level, scale, trend | **основной метод H8** |
| sel_align_noshort | выбор без Short | описательно: держится ли выигрыш на удалении истории |
| fix_level, fix_scale, fix_trend | преобразование всегда, без выбора | описательно; разбивка по типам — материал для H9 |
| fix_{level,scale,trend}_α | частичная коррекция, α ∈ {0.25, 0.5, 0.75} | абляция, описательно |
| sel_partial | выбор из Original, Short и всех 12 сочетаний (преобразование × α ∈ {0.25, 0.5, 0.75, 1}) | дополнительно |
| full, L64, L128, oracle_trim, det_trim, mix_hind (пилот H7) | сравнения | из кеша и прежних результатов |

## 7. Критерий

**Основной (Bolt H64, seed 0, sel_align)** — в том же виде, что H7: нижняя граница 95% интервала TG64 > 0 по всем change **и** верхняя граница 95% интервала SH на none ≤ 0.01.

**Вторая часть (согласована; по формулировке H8 «меньше, чем удаление»):** на change 0 ≤ d < 64 парное геометрическое среднее MAE(sel_align) / MAE(Short L64) и MAE(sel_align) / MAE(det_trim) < 1, верхняя граница 95% интервала < 1 (тот же бутстреп по рядам). **H8 поддержана (разведочно), только если выполнены обе части.**

Остальное (Bolt H16, Chronos-2, фиксированные преобразования, α, разбивки, покрытие, WIS, d*) — описательно.

## 8. Вычисления и хранение

- Новые прогнозы на каждое окно seed 0 (все 32 980 окон, включая pos = −128 и −120, нужные как hindcast): 3 полных преобразования + 9 частичных = 12 контекстов. Bolt: ≈ 396 тыс. прогнозов, ≈ 25–30 мин CPU. Chronos-2: ×2 горизонта ≈ 790 тыс., ≈ 40 мин GPU.
- Хранение: `results/cache/synth_v1/<модель>/aligned_v1/<ячейка>.npz` (подпапка: не читается `load_forecasts`). Полные квантили H64 (и H16 у Chronos-2) для трёх полных преобразований — нужны направлению 3; для частичных — только медиана первых 16 шагов (hindcast) и метрики окна (MAE, WIS, покрытие, ширина). Оценка Bolt: ≈ 230 МБ, Chronos-2 ≈ 290 МБ — **прирост истории git**, решить, коммитить ли.
- Сверки, на которых скрипт падает: Original через тот же путь совпадает с кешем L512 (≤ 1e-4 std контекста) на выборке окон; одиночный вызов = батч; α = 0 даёт исходный контекст точно (тест).
