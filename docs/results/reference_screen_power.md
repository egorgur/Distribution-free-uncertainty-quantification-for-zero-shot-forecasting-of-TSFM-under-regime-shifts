# Мощность предварительного экрана эталонов

2026-11-13. **Диагностика процедуры, не H1–H3 и не новый отбор газа.**
Правила новой сетки записаны до расчёта в
`docs/protocol_reference_screen_power.md` и `docs/decisions.md`.
Предыдущая проверка реальных данных — `docs/results/gas_reference_audit.md`.

## Проверка с известным ответом

Без изменения исходного `screen_tail` проверены 20 ячеек:
AR(1) с phi = 0 / 0.5 / 0.9 / 0.98; стационарный процесс, линейный дрейф
0.5 и 2 исходных std, скачок среднего 1 std и увеличение std вдвое.
Стационарный AR начинается из своего распределения N(0,1), поэтому отсутствие
burn-in не создаёт искусственного перехода. Большое phi означает сильную
зависимость, но не «длинную память» в строгом асимптотическом смысле.

На ячейку 100 независимых панелей по 16 каналов; всего **32 000 траекторий**,
2000 вызовов экрана с 1000 bootstrap-повторами. Исходные допуски и требование
прохождения при обеих длинах bootstrap 5/10 сохранены. Результаты всех пяти
условий получены из общих AR-траекторий внутри панели для парного сравнения.
Ни один газовый файл не читался, TSFM не запускались.

## Главный результат

**На всех 20 ячейках оба экрана приняли 0 траекторий.** Это включает
**6400 заведомо стационарных траекторий** с четырьмя уровнями зависимости.
Неопределённых результатов из-за нулевой дисперсии нет.

| phi | Основной экран: принято стабильных | Дополнительный: принято стабильных | Только точечные оценки, основной | Только точечные, дополнительный |
|---:|---:|---:|---:|---:|
| 0 | 0/1600 | 0/1600 | 25.50% | 86.00% |
| 0.5 | 0/1600 | 0/1600 | 10.125% | 47.9375% |
| 0.9 | 0/1600 | 0/1600 | 0.25% | 4.3125% |
| 0.98 | 0/1600 | 0/1600 | 0% | 1.1875% |

Последние два столбца **не являются альтернативным правилом отбора**. Они
показывают вклад случайного разброса оценок и расширения до доверительных
границ: даже точечные оценки плохо принимают сильно зависимый стационарный
процесс на короткой реализации. У независимого шума дополнительный точечный
экран принимает также 65.5% слабого дрейфа `linear_0.5`; он не заменяет
проверку эквивалентности. Такой дрейф может частично укладываться в практические
допуски, поэтому эта доля не объявляется универсальной ошибкой I рода.

Из-за общих bootstrap-индексов интервалы Монте-Карло считаются по **100 панелям**,
а не по 1600 якобы независимым решениям. При нуле принятых панелей консервативная
поточечная верхняя 95%-граница для средней вероятности принятия канала — **3.62%**,
через событие «хотя бы один принят в панели». Это граница для конкретной ячейки,
не одновременная гарантия для всей сетки. Для ненулевых диагностических долей
использована нормальная аппроксимация по панелям; при редких событиях её покрытие
может быть неточным.

Заранее заданный ориентир применимости **не выполнен при каждом phi**:
нижняя граница принятия стационарного процесса должна была быть ≥80%.
Верхний ориентир ≤5% для принятия трёх сильных альтернатив выполнен только
потому, что экран не принимает вообще ничего. **Это не свидетельство полезного
разделения стабильности и изменений.**

## Что нельзя заключать

- Нулевой отбор газа по прежней процедуре **не доказывает отсутствия устойчивых
  режимов**, непригодности набора или отрицательной H1.
- Мы измерили частоты решений на указанном генераторе. Это не доказательство
  номинального покрытия bootstrap-границ и не калибровка по всем зависимым законам.
- Bootstrap отдельно внутри 40-точечных блоков не воспроизводит всю зависимость
  между ними; при большом phi нужны отдельные проверки покрытия.
- Однородность средних/дисперсий не равна устойчивости ошибки TSFM или физическому
  установившемуся состоянию. Устойчивый прогнозируемый режим может включать
  повторяемую динамику; требование «ряд почти плоский» сильнее постановки научрука.

## Иллюстрация требуемой точности, не новая процедура

В `mean_only_planning.csv` отдельно сохранён аналитический ориентир: известная
маргинальная дисперсия 1, истинные разности средних 0, три пары, консервативная
поправка Бонферрони на семейный уровень 97.5%; только среднее, без дисперсии.
Это **не расчёт мощности 80%, не минимальная длина для исходного экрана и не
предлагаемые новые хвосты**. Формула дисперсии среднего AR проверена прямой суммой
ковариаций в тестах. Для допуска 0.25 ориентир полной длины трёх блоков:

| phi | Иллюстративное число отсчётов |
|---:|---:|
| 0 | 669 |
| 0.5 | 2001 |
| 0.9 | 12 669 |
| 0.98 | 66 003 |

Разрешающая способность зависит от длительности физической записи и корреляции,
не только от частоты дискретизации. Замена 1 Гц на 10 Гц не создаёт в десять раз
больше независимой информации. Эти числа не разрешают менять прежние 120 секунд.

## Предлагаемое продолжение — до нового отбора

1. **Не тюнить экран v1 и не применять его как автоматическое обоснование
   знаменателя.** Нужна опора на физику эксперимента и точность самого эталона.
2. Для газа установить по полному описанию эксперимента/консультации, какие
   измеренные состояния действительно считаются установившимися и какие изменения
   допустимы. [Первичная страница UCI 322](https://archive.ics.uci.edu/dataset/322/gas+sensor+array+under+dynamic+gas+mixtures)
   подтверждает камеру 60 мл и поток 300 мл/мин, но **не задаёт проверенный порог
   установления показаний или устойчивости ошибки TSFM**. Отношение объёма к потоку
   даёт 12 с номинального обмена; это не время реакции/восстановления датчика
   и не обоснование отступа 30 с. Полный текст исходной статьи ещё не проверен.
3. Если физически защищаемый эталон здесь установить нельзя, **искать набор с
   документированными длительными контрольными режимами и повторными запусками**,
   сохраняя газ для отдельного разведочного анализа только с разрешения.
   Близкое название не гарантирует подходящих рядов: [UCI 270](https://archive.ics.uci.edu/dataset/270/gas+sensor+array+drift+dataset+at+different+concentrations)
   содержит 128 извлечённых признаков на эксперимент, а не опубликованные в
   этой поставке непрерывные сырые траектории; механически заменить им UCI 322 нельзя.

Проверенный в этом продолжении приоритет дополнительного поиска — **PRONTO**,
физический стенд Cranfield, непрерывная SCADA 1 Гц и операционный журнал.
Источники и ограничения сохранены в `docs/real_data_candidates.md`, раздел
«PRONTO». Нужна проверка длительностей плато по журналу; указанные 5–7 минут
ожидания стабилизации не доказывают наличия длительного эталона. В последующем
продолжении получены журнал и один CSV Test11:
`docs/results/pronto_reference_audit.md`. Полный набор не скачан, пригодность
эталона и независимость запусков ещё не установлены.
Доступный полный текст Fonollosa et al. для газа подтвердить не удалось;
это не доказательство отсутствия легальной авторской копии.

**До реального переотбора требуется решение:** предметно обоснованный эталон для
газа либо новый физический набор с подходящим контролем. Новый количественный
экран без такого основания здесь не утверждается. `mae_ratio`, H1–H3 и запрет
на использование будущего/эталонных ошибок во входах S1/S4 остаются неизменными.
Если будет новая процедура, сначала фиксируются допуски и генераторы для проверки
её мощности/покрытия, затем независимая проверка, и только потом реальные данные.
