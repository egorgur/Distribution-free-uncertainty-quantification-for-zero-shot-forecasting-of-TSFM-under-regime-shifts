## Что не меняется

Вызвать существующий `src/gas_reference.py:screen_tail` без изменений:
120 отсчётов, три блока по 40, bootstrap 5/10, 1000 повторов; одновременно
сохранять исходные основной и дополнительный экраны 0.25/1.5 и 0.5/2.0.
Считать окончательное прохождение только при обеих длинах bootstrap.
Отдельно показать прохождение по одним точечным оценкам **только как
диагностику потери точности**, не как предлагаемый способ отбора данных.

## Генератор с известными свойствами

Базовый процесс AR(1): `z[0] ~ N(0,1)`,
`z[t] = phi*z[t-1] + sqrt(1-phi²)*epsilon[t]`, `epsilon ~ N(0,1)`.
Начальное распределение стационарное, маргинальная дисперсия 1; burn-in не нужен.
Фиксированные `phi = 0, 0.5, 0.9, 0.98`. При phi0 это iid-контроль, последние
два значения проверяют длинную память; это не подгонка к параметрам газа.

Пять условий при каждом phi:

1. `stationary`: базовый процесс без изменения закона.
2. `linear_0.5`: прибавить линейное среднее от 0 до 0.5 за 120 отсчётов.
3. `linear_2`: то же от 0 до 2.
4. `mean_step_1`: прибавить 1 к отсчётам 60…119 (индексы от нуля).
5. `scale_step_2`: умножить отсчёты 60…119 на 2. Это отношение **std**, не дисперсий.

Для первых трёх дополнительных условий эффект выражен в известной исходной
маргинальной std=1, а не в std наблюдённого ряда. Слабый дрейф может находиться
внутри практических допусков: его принятие не автоматически «ошибка теста».
Генератор не описывает всю физику газового стенда; результаты не обещают переноса.

## Повторы, случайность и стоимость

**100 независимых панелей × 16 независимых каналов** = 1600 траекторий на ячейку,
20 ячеек, всего 32 000 траекторий, 2000 вызовов исходного экрана. Панель —
технический батч; внутри неё bootstrap использует общие индексы каналов,
поэтому неопределённость Монте-Карло считать **по независимым панелям**.

Seed генератора `20261113`, bootstrap отдельный `20261114`; дочерние seed
определяются номерами phi/условия/панели. Интервалы ниже не требуют случайности. Использовать
общий базовый AR для пяти условий одной phi/панели: это парное сравнение,
не дополнительные независимые повторы. Старые seed777/0 в эту сетку не входят.

Оценка ресурсов до расчёта: один 120×16 массив, до 1000×3×40×16 bootstrap-чисел
в памяти (~15 МБ на массив), результаты — решения/диагностика, не сырые bootstrap.
Ожидаемый порядок — минуты на CPU, без моделей и новых зависимостей.

## Отчёт и заранее заданная интерпретация

- Доли прохождения для обоих экранов и точечного диагностического варианта;
  отдельно отказ по среднему и дисперсии и неопределённые результаты.
- Двусторонние 95% интервалы Монте-Карло: среднее долей внутри 100 панелей,
  затем нормальная аппроксимация по std этих независимых долей, границы [0,1].
  При всех нулях/единицах вместо вырожденного интервала для полной доли дать
  консервативную границу Клоппера–Пирсона по числу панелей с хотя бы одним
  прохождением/отказом: вероятность отдельного канала ограничена вероятностью
  соответствующего события панели. При 100 нулевых панелях верхняя граница
  около 3.62%, поэтому ориентир 5% разрешим. Пометить тип интервала явно.
- Для стационарного условия прохождение — способность подтвердить практически
  малое изменение. Для альтернатив — частота принятия заданного нестационарного
  закона; это не единая ошибка I рода для всего класса нестационарности.
- Заранее выбранный диагностический ориентир: нижняя граница прохождения
  стационарного условия ≥0.80 и верхняя граница принятия `linear_2`,
  `mean_step_1`, `scale_step_2` ≤0.05 при каждом phi. Это строгая проверка
  применимости к данной сетке, не универсальная гарантия. Если не выполнено,
  не использовать экран как автоматическое обоснование отбора эталонов.
- **Никаких новых допусков, длин хвоста или лучшего phi по результату.**
  Выбор новой процедуры потребует отдельного решения до реального переотбора.
  Не считать это формальной калибровкой экрана или оценкой `mae_ratio`.
- Сохранить весь результат/конфигурацию/хеши/seed/версии/время, тесты генератора
  и агрегации, график долей. Исторические результаты газа не перезаписывать.
