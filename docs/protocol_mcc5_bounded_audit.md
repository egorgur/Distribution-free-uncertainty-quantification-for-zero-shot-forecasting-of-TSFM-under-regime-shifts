# Ограниченный аудит одной записи MCC5-THU

2026-11-13. Зафиксировано до загрузки числового CSV. Это описательная проверка
кандидата, не утверждённый прогнозный протокол и не новый экран устойчивости.

## Источник и выбор

- Использовать связанное карточкой Mendeley зеркало Hugging Face на commit
  `897bc5d2504980418249f98e733bfd7f61056186`, только `torque_circulation.zip`.
  Эквивалентность Mendeley V1/V2 не предполагается доказанной.
- Сначала сохранить небольшую метадату, README и полное оглавление этого ZIP.
  Затем выбрать один healthy-файл variable-torque с метками20Nm/1000rpm;
  при нескольких — первый по лексикографическому пути, служебные `._` исключить.
  Если такой метки нет или имя неоднозначно, остановиться перед сигналами
  и уточнить выбор по оглавлению, не по данным/ошибке модели.
- Записать точный путь в журнал до чтения CSV. Получить полную запись, не
  выбирать удобные секунды. Не склеивать записи и не загружать другие условия.

## Ограничения загрузки

HTTP Range должен вернуть206 с точным Content-Range; ответ200 отвергается
**до чтения тела**. Ограничения:128МиБ сетевых диапазонов для одного этапа,
96МиБ сжатого выбранного члена,256МиБ распакованного CSV,2МиБ на документ,
4096членов ZIP. Архив целиком не скачивать. Сохранить CRC выбранного члена,
локальный SHA256, размеры, pinned-версию, диапазоны и исходные документы.
Не заявлять проверку LFS-хеша полного многогигабайтного ZIP.

## До интерпретации динамики

Проверить все строки/столбцы, заголовок, разделитель, ширину, NaN/Inf,
константы/дубли, число отсчётов. При наличии времени проверить его как данные;
без времени индекс/12800 — только **номинальное** время по документации,
не доказанная аппаратная непрерывность. Не исправлять и не сортировать исходник.
Схему8/9столбцов и единицы сопоставить с README/таблицей4 статьи. Сохранять
статистики в исходных единицах; автоматическую конвертацию напряжения не делать.

## Описательная динамика, без отбора эталона

- Для всех каналов сохранить секундные средние/std/min/max и диагностический
  график; для момента дополнительно четвертьсекундные агрегаты. Это не
  утверждённая модельная частота или предобработка.
- По документированному примеру задания отдельно описать интервалы10–30,
  35–55,60–80с и их последовательные5-секундные части: среднее/std/крайние
  значения, линейный тренд. Эти интервалы **не объявлять установившимися**.
  Если фактический профиль иной, показать расхождение, а не передвигать интервалы.
- Канал key-phase описать через диапазон/частоту фронтов. Порог фронта —
  середина наблюдённого min/max, только диагностика; не назначать RPM без
  обоснованного числа импульсов на оборот. Краткие импульсы/дребезг раскрыть.
- Геометрия L512/H64 при исходных12.8кГц и иллюстрациях100/10/1Гц — арифметика,
  не выбор частоты по удобному результату. Каналы/окна/два плато одного запуска
  не независимые повторы.

Устойчивость и точность эталонной MAE этой проверкой не доказываются. При
неопределённых единицах или установлении сохранить вопрос открытым. Любая
новая статистическая процедура отбора требует отдельного согласования и
проверки мощности до отбора. TSFM/S1/S4/MAE/AURC не считать; L/H и требование
устойчивого эталона не менять.
