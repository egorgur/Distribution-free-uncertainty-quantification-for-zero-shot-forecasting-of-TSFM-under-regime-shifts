## Ограничения

- Синтетика synth_v1, 10 рядов на ячейку; состав окон задан сеткой (одно окно на каждое d с шагом 8).
- П3 — приближение reset-and-grow: статья «Breaking context inertia» не прочитана; детектор П3 видит полное окно 512, а не обрезанный контекст; окна идут с шагом 8.
- Обрезка по τ′ этапа B кратна 16 точкам (патч), по истинной τ — нет.
- В окнах с залипанием обрезка по его началу даёт постоянный контекст и почти точный прогноз (r → 0, log r ограничен снизу log 1e-06). Такие окна сильно сдвигают геометрическое среднее столбца «все»; столбцы «со сменой», «без смены», «все без аномалий» и таблица по зонам их не содержат. Столбец «все без аномалий» и ограничение таблицы по зонам добавлены после первого расчёта (описание).
- Пороги перенесены с seed 1; интервалы их разброс не учитывают.
- Сигнал этапа A (S2) и ожидание «польза — при смене частоты и тренда» выбраны по результатам seed 0 (этапы 4 и B).
