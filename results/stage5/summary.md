## Как читать

- **Окно со сменой** — change и drift при 0 ≤ d < L − 1 (в контексте есть точка смены). **Без смены** — весь контекст в одном устойчивом режиме: d < 0 любого класса, контроль без изменений, change при d ≥ L − 1, drift после конца подъёма, аномалия, уже вышедшая из контекста.
- **Порог** каждого представления — 95-й перцентиль счёта на окнах без смены seed 1 (FAR 5%); на seed 0 тот же.
- **Попадание** — детектор сработал и |τ′ − τ| ≤ δ (у drift τ′ ∈ [τ − δ, τ + 128 + δ]); основной δ = 32. Срабатывание в окне со сменой, но мимо — и ложная тревога, и пропуск. **F1** = 2·TP / (2·TP + FP + FN) по окнам со сменой и всем окнам без смены вместе. **FAR** — доля окон без смены, где детектор сработал. **Полнота** — доля окон со сменой с попаданием.
- **Задержка** — первое d ≥ 0 с попаданием в ряду, медиана по рядам; в скобках — доля рядов без попадания до d = 504. «> 504» — больше половины рядов без попадания.
- **Глубина** — номер блока / число блоков; вход энкодера — 0, final — выход последнего блока после итоговой layer norm (глубина 1, как у последнего блока).
- Лучший сырой метод по seed 1: **р2 статистики патча** (на seed 0 лучший — р2 статистики патча).

## Ограничения

- Синтетика synth_v1, 10 рядов на ячейку, одна точка смены на ряд; состав окон задан сеткой d.
- При FAR 5% часть попаданий случайна: случайная τ′ ∈ [32, 480] попадает в ±32 от τ примерно в 13% случаев. Поэтому полнота при малых d и задержки меньше ~32 — с оговоркой. У drift окно попадания шире ([τ − 32, τ + 160]), и случайная τ′ попадает примерно в 34% случаев (39–40% при d ≥ 128).
- Минимальный сегмент 32 точки: при d < 31 правый сегмент не помещается, и попасть можно только в пределах δ.
- Порог перенесён с seed 1 без пересчёта; интервалы не учитывают разброс порога.
- Профиль по слоям (кроме выбранного уровня) — описание, без поправки на множественные сравнения.
