## 3. Тема и суть проблемы

**Исходная тема (из списка кафедры):** «Обнаружение OOD-режимов перед прогнозированием временного ряда» (направление Time-Series Foundation Models).

**Уточнённая тема:** *Безразметочная оценка надёжности zero-shot прогноза Time-Series Foundation Models при смене режима технологического процесса.*

**Проблема простыми словами.** TSFM (Chronos, TimesFM, Moirai и др.) прогнозируют ряды без дообучения, но не умеют сообщать, когда их прогнозу нельзя верить. Хуже всего — в моменты **смены режима**: при переходе от одного состояния процесса к другому ошибка резко растёт, а прогнозные интервалы перестают покрывать реальные значения. Существующие методы отказа от прогноза для TSFM требуют заранее накопить ошибки модели на целевом объекте (разметку), что противоречит идее zero-shot.

**Ключевое наблюдение из литературы:**

- сам по себе необычный (OOD) режим часто **не опасен** — если он длится, модель подстраивается по контексту (2607.12454);
- опасны **переходы** между режимами (2606.18367: ошибка в переходах ~11 vs ~3 в среднем, покрытие 90% интервалов падает до ~55%).

Поэтому цель — ловить не «непохожесть», а **ситуации, где прогноз станет ненадёжным**.

**Центральная идея метода.** Если модель по-разному прогнозирует по короткому и длинному контексту, значит процесс в недавнем прошлом не похож на более давнее → вероятна смена режима. Теоретическая опора: длинный контекст уменьшает неопределённость относительно порождающего процесса (2606.01999).

## 4. Формулировка задачи

**Дано:**

- временной ряд x₁, …, xₜ (промышленный сигнал);
- замороженная TSFM `f`, которая по контексту длины `L` выдаёт вероятностный (квантильный) прогноз на горизонт `H`;
- нет размеченных ошибок и обучающих данных на целевом объекте.

**Требуется** построить функцию надёжности `s(x_{1:t}, f) → ℝ`, которая:

1. использует только наблюдённый контекст и выходы / внутренние представления модели;
2. принимает большие значения на окнах с высокой будущей ошибкой прогноза;
3. позволяет отказываться от ненадёжных прогнозов (selective forecasting) лучше базовых сигналов;
4. может обнаруживать точку смены режима внутри контекста — для обрезки контекста и пересчёта прогноза.

**Ограничения:** без дообучения; стоимость ≤ K дополнительных прогонов модели (K ≤ 5).

**Важно:** смену режима **внутри горизонта прогноза** по истории предсказать нельзя — такие окна анализируются отдельно и не считаются провалом метода.

## 5. Сигналы надёжности

| Код | Сигнал | Тип |
| --- | --- | --- |
| S1 | Ширина прогнозного интервала `(q0.9 − q0.1)`, нормированная на масштаб ряда | Бейзлайн |
| S2 | Ошибка модели на последних известных точках (прогноз «назад» на уже наблюдённые значения) | Сильный безразметочный бейзлайн |
| S3 | Классические детекторы смены: CUSUM, PELT (`ruptures`), KS-тест начало vs конец контекста | Бейзлайн |
| **S4** | **Расхождение прогнозов по разным длинам контекста** `L ∈ {L₁…Lₖ}` | **Предлагаемый** |
| **S5** | **Сдвиг эмбеддингов** последнего фрагмента относительно предыдущих, с разных слоёв энкодера | **Предлагаемый** |
| S6 | Обучаемый предсказатель ошибки на размеченной валидации (аналог мета-обучения) | Верхняя граница с разметкой |

Нормировка: все сигналы и ошибки — scale-free (делить на масштаб контекста, например MAE сезонного наивного прогноза или std контекста).

## 6. Гипотезы

| ID | Гипотеза | Проверка |
| --- | --- | --- |
| H1 | Ошибка TSFM значимо выше в **переходных** окнах, чем в стабильных; в устоявшемся новом режиме возвращается к норме | MASE/CRPS по группам «стабильно / переход / новый режим», тест Манна–Уитни |
| H2 | Ширина интервала (S1) слабо связана с ошибкой в переходах; покрытие 80%-интервалов там ниже номинала | Покрытие по группам; Спирмен S1 vs ошибка по группам |
| H3 | S4 сильнее коррелирует с ошибкой и даёт меньший AURC, чем S1 и S3, особенно в переходах | AURC, ошибка при покрытии 80/90%, AUROC для «топ-10% худших окон» |
| H4 | Эмбеддинги **средних** слоёв энкодера лучше детектируют смену, чем последнего | Перебор слоёв; F1 с допуском ±δ; задержка обнаружения |
| H5 | Обрезка контекста по обнаруженной точке смены снижает ошибку после перехода, приближаясь к «оракулу» | Полный контекст / обрезка по детектору / по истинной точке; тест Уилкоксона |
| H6 | Выводы H3 переносятся между архитектурами TSFM; S4 достигает заметной доли эффекта S6 | Ранжирование сигналов по AURC для каждой модели; отношение выигрышей |

## 8. Технические заметки

### Модели и библиотеки (проверять актуальные версии и API!)

- Chronos / Chronos-Bolt / Chronos-2 — пакет `chronos-forecasting` (Amazon), веса на Hugging Face `amazon/chronos-bolt-*`, `amazon/chronos-2`. Лицензия Apache-2.0.
- TimesFM — пакет `timesfm` (Google), веса `google/timesfm-2.5-200m-pytorch`. Версии 1.0–2.5 — Apache-2.0; веса 3.0 — некоммерческие.
- Moirai — пакет `uni2ts` (Salesforce). Лицензия CC-BY-NC-4.0 (для учебного исследования допустимо).
- Детекция смены режима: `ruptures`.
- Базовые метрики/бейзлайны: `statsforecast` / `utilsforecast` (Nixtla), либо свои реализации.

### Метрики

- **MASE** — MAE, делённая на MAE сезонного наивного прогноза на контексте.
- **CRPS** — по квантилям (weighted quantile loss как приближение).
- **Покрытие** — доля фактических значений внутри интервала [q0.1, q0.9]; номинал 80%.
- **Риск–покрытие (selective forecasting):** сортируем окна по сигналу, отбрасываем долю самых «подозрительных», считаем среднюю ошибку на оставшихся. **AURC** — площадь под этой кривой (меньше — лучше). Сравнивать с отбором случайно и с «оракулом» (отбор по истинной ошибке).
- **Детекция смены:** F1 с допуском ±δ точек, средняя задержка обнаружения.

### Мера расхождения для S4 (стартовый вариант)

Прогнозы медиан `m_L` для каждой длины контекста `L`; сигнал = std (или средний попарный |Δ|) медиан по `L`, усреднённый по горизонту и нормированный на масштаб контекста. Альтернатива — расстояние между квантильными прогнозами.

## 9. Ключевая литература

### Прямые конкуренты / ближайшие работы

- **Shapelets-Enriched Selective Forecasting using TSFMs** — arXiv:2601.11821 (2026). Отказ от прогноза по шейплетам; требует ошибок на валидации целевого домена; модель TTM; ETT/Exchange/Traffic.
- **Selective Time Series Forecasting via Metalearning** — arXiv:2606.23448 (2026). Мета-модель предсказывает перцентиль ошибки; требует обучения.
- **The Time-Energy Model** — TMLR 2025. Selective forecasting на energy-based models для обучаемых детерминированных моделей.

### Где и почему TSFM ломаются

- **Do TSFM Benchmarks Hide Regime-Dependent Failures?** — arXiv:2606.18367 (ICML 2026 workshop). Провалы в переходах на трафике. **Ключевая.**
- **Causal Analysis for TSFMs** — arXiv:2608.24303. Внезапные провалы на синтетике со сменой режима.
- **Performance of Zero-Shot TSFMs on Cloud Data** — arXiv:2502.12944. Малое изменение контекста → сильно другой прогноз.
- **Position: Universal TSFMs Rest on a Category Error** — arXiv:2602.05287.
- **TSFMs for Electricity Price Forecasting** — arXiv:2607.02623. Ошибка Chronos-2 в спайках выше примерно на 128%.

### Неопределённость и калибровка

- **Beyond Accuracy: Are TSFMs Well-Calibrated?** — arXiv:2510.16060 (ICLR 2026). В среднем хорошо откалиброваны.
- **TSFMs for Energy Load Forecasting on Consumer Hardware** — arXiv:2602.10848. Большие различия калибровки между моделями.
- **Evaluating Accuracy and Probabilistic Reliability of Zero-Shot TSFMs** — arXiv:2609.25788.
- **Quantifying Uncertainty in Foundation Models via Ensembles** — NeurIPS 2022 Workshop (Sun et al.). Несогласованность ансамбля как неопределённость — аналогия для S4.

### Теория контекста и смены режима

- **Why Do Time Series Models Need Long Context Windows?** — arXiv:2606.01999. Длинный контекст снижает неопределённость о порождающем процессе. **Теоретическая опора S4.**
- **In-Context Learning Under Regime Change** — arXiv:2604.16988 (ICML 2026). Знание точки смены улучшает прогноз TSFM без переобучения. **Опора H5.**
- **Dissecting Chronos (SAE)** — arXiv:2603.10071. Признаки детекции изменений сосредоточены в средних слоях энкодера. **Опора H4.**

### Аномалии и эмбеддинги TSFM

- **Exploring Zero-Shot FMs for MTS Anomaly Detection** — arXiv:2607.12454. TimesFM на SWaT; ошибка пикует на границах аномалий; CPD — «будущая работа». **Ключевая.**
- **THEMIS** — arXiv:2510.03911. Эмбеддинги Chronos + LOF.
- **ChronosAD** — arXiv:2606.01300.
- **Adaptive Conformal Anomaly Detection with TSFMs** (IBM) — arXiv:2604.20122.
- **StarEmbed** — arXiv:2510.06200 (ICML 2026). Эмбеддинги Chronos-Bolt хорошо выделяют OOD-объекты.

### OOD для временных рядов (общее)

- **TS-OOD** — arXiv:2502.15901.
- **Hyperspherical Time–Frequency Representations for TS OOD** — arXiv:2605.31155 (IJCAI 2026).
- **CODiT** — arXiv:2207.11769.
- **TS-CP²** (CPD через эмбеддинги соседних окон) — arXiv:2011.14097.

## 10. Глоссарий

- **TSFM** — Time-Series Foundation Model, предобученная на множестве рядов модель для zero-shot прогноза.
- **Zero-shot** — прогноз без дообучения на целевых данных.
- **Контекст** — участок истории, подаваемый модели на вход.
- **Горизонт** — сколько точек вперёд прогнозируем.
- **Смена режима (regime change)** — переход процесса из одного устойчивого состояния в другое.
- **OOD** — out-of-distribution, данные, непохожие на привычные модели.
- **Selective forecasting / reject option** — прогноз с правом отказа на ненадёжных окнах.
- **AURC** — площадь под кривой риск–покрытие.
- **CPD** — change-point detection, обнаружение точек смены.
